# Макеты до кода

Три размеченных цифровых макета: список, подробности, избранное. Созданы до исходников экранов и сохранены первым локальным коммитом. SVG можно импортировать в Figma.

**Честная оговорка:** макеты подготовлены с помощью Codex. Задание требует собственные эскизы на бумаге или в Figma: перед сдачей импортируйте их в Figma, проверьте структуру и осознанно доработайте либо нарисуйте собственные эскизы. Не выдавайте эти файлы за самостоятельно нарисованные.
