# Защита: 5–7 минут

## Демо, примерно 1 минута
1. Открой каталог и пролистай 12 карточек.
2. Выбери категорию «Культура»: список сократится; «Все» вернёт все места.
3. Открой карточку: navController передаёт её ID в detail/{id}.
4. Сохрани место, нажми назад, открой сердечко в верхней панели.
5. Удали место из избранного: появляется дружелюбное пустое состояние.
6. Переключи системную тёмную тему и покажи тот же интерфейс.

## Вопросы и объяснения
- **Как ID попадает в подробности?** onOpen вызывает navigate("detail/$id"). NavHost объявляет detail/{id} с NavType.IntType. entry.arguments.getInt("id") читает число, Places.find ищет объект.
- **Почему изменяется UI при фильтрации?** remember хранит mutableStateOf(category). При смене значения Compose повторно вычисляет видимый список и перерисовывает нужные элементы.
- **Где цвета?** Только Theme.kt: LightColors / DarkColors. Экраны читают MaterialTheme.colorScheme. Системная тема выбирается через isSystemInDarkTheme.
- **Что делает Modifier.weight(1f)?** Текстовая Column в Row занимает доступное место, оставляя пространство для сердечка. maxLines=1 и Ellipsis не позволяют длинному имени вытеснить кнопку.
- **Чем LazyColumn отличается от Column?** LazyColumn создаёт необходимые видимые элементы и умеет прокручиваться; Column раскладывает всё сразу.
- **Что переиспользуется?** PlaceCard на двух экранах, SectionHeader на трёх, TagChip на двух. Их данные и действия передаются параметрами.
- **Почему state избранного находится над NavHost?** Оба списка и подробности видят одно состояние. SharedPreferences сохраняет ID на устройстве после закрытия приложения.
- **Что если ID не существует?** Places.find возвращает null; DetailScreen показывает сообщение и рабочую кнопку назад.
- **Нужен ли интернет?** Для первого скачивания зависимостей — да; само приложение работает офлайн.

## Три простых изменения для тренировки
1. Изменить расстояние между карточками: ListScreen → Arrangement.spacedBy(Spacing.lg).
2. Разрешить две строки заголовка карточки: PlaceCard → Text(place.name), maxLines = 2.
3. Изменить основной цвет: Theme.kt → primary в светлой и тёмной палитрах.

Каждое изменение сделай самостоятельно в Android Studio и запусти приложение. На защите AI запрещён. Этот файл помогает подготовиться, но не заменяет понимание исходников.
